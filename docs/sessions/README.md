# Registros de sessão

Crie um arquivo `AAAA-MM-DD-resumo.md` por sessão relevante. Se houver mais de uma no mesmo dia, acrescente um sufixo numérico.

O registro deve ser curto e conter objetivo, realizado, decisões, validações, pendências e próxima ação. Não copie o diff nem repita todo o `PROJECT_STATUS.md`.

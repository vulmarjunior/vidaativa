# Registros de decisão arquitetural

Use um ADR para escolhas de impacto duradouro, difícil reversão ou efeito em vários módulos.

Formato: `ADR-NNN-titulo.md`.

Cada ADR contém contexto, decisão, consequências e estado. ADR aceito não é apagado; uma nova decisão o substitui explicitamente.

- `ADR-001-single-tenant.md`
- `ADR-002-catalogo-extensivel-e-planos.md`

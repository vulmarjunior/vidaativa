# Gestão de tarefas

## Pastas

- `active/`: somente tarefas em execução ou prontas para continuação imediata.
- `backlog/`: tarefas especificadas, mas não iniciadas.
- `completed/`: tarefas encerradas com evidências de validação.

## Nome

`TASK-NNN-descricao-curta.md`

## Campos obrigatórios

- status, prioridade, módulo, dependências e data;
- objetivo;
- escopo e fora do escopo;
- critérios de aceite verificáveis;
- progresso;
- arquivos afetados;
- riscos ou bloqueios;
- `Onde continuar` com uma ação concreta;
- validações realmente executadas.

Ao encerrar, mova o arquivo para `completed/`, atualize `PROJECT_STATUS.md`, o módulo, `CHANGELOG.md` e o registro da sessão.
